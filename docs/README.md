# zellerlab/flexprofiler: Documentation

The zellerlab/flexprofiler documentation is split into the following pages:

- [Usage](usage.md)
  - An overview of how the pipeline works, how to run it and a description of all of the different command-line flags.
- [Parameters](parameters.md)
  - All the pipeline parameters.
- [Databases](databases.md)
  - How to download or build the databases of each profiling tool.
- [Output](output.md)
  - An overview of the different results produced by the pipeline and how to interpret them.
- [Zeller lab](zellerlab.md)
  - Pre-configured options and scripts for the Zeller lab.
